# アーキテクチャ進捗確認

## 目的

`docs/architecture/README.md` と最新のアーキテクチャスナップショット、`QWEN.md` を読み取り、プロジェクトのこれまでの進捗をコンパクトに要約する。

実装着手前に `tasks/` 以下のタスクファイルを読む前に呼び出し、現在地を把握するために使用する。

## 手順

### 1. アーキテクチャ一覧の取得

`docs/architecture/README.md` を読み、スナップショット一覧を取得する。

### 2. 最新スナップショットの読み取り

一覧から最新のスナップショットファイル（日付が最も新しいもの）を特定し、全文を読み取る。

### 3. QWEN.md の読み取り

プロジェクトルートの `QWEN.md` を読み取り、現在の進捗状況セクションを確認する。

### 4. 最新の git ログ確認

`git log --oneline -10` を実行し、直近のコミットから現在のブランチの状況を把握する。

### 5. 要約の出力

以下の形式でMarkdown出力する:

```markdown
## アーキテクチャ進捗サマリ

### 現在地
- 最終スナップショット: YYYY-MM-DD — {タイトル}
- 現在のブランチ: {branch}
- 直近のコミット: {最新コミットメッセージ}

### 実装済み機能
- ...

### 進行中/未着手
- ...

### 次にやるべきこと
- {次のタスクへの示唆}
```

## 注意点

- このスキルは **読み取り専用** である。いかなるファイルも変更・作成してはならない。
- 最新スナップショットの `## Next steps / improvements` セクションがあれば特に重視する。
- `QWEN.md` の `## Current Progress` セクションも参考にする。
- 出力は100〜200行程度のコンパクトな要約にまとめる。
- `tasks/` ディレクトリのファイルはこのスキルでは読み取らない（後続の工程で別途読み取る）。
