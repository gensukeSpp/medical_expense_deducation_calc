実行方法

bash
uv run python main.py \
    --input-dir ~/Downloads/receipts \
    --image-name 領収書.jpg \
    --processed-dir processed \
    --preprocess-mode clahe+adaptive \
    --target-short-side 960


動作フロー（確認済みの実装）
1. --image-name で指定した単体画像を処理（processor.py → ImageProcessingService）
2. 1回目の OCR で raw_data.json を出力
3. topmost の Confidence を判定（coord_normalizer.get_topmost_confidence）
4. 0.8 未満（低 Confidence）かつ --preprocess-mode が none でない場合だけ、CLAHE/適応的二値化を適用して OCR を再試行（1回）
5. 前処理済み画像を processed/preprocessed_<画像名>.jpg に保存、raw は原本と前処理済みの2ファイルを残す

--preprocess-mode の選択肢（app/args.py:45 で定義）
- none …… デフォルト。前処理しない（従来動作と同一）
- clahe …… CLAHE のみ
- adaptive …… 適応的二値化のみ
- clahe+adaptive …… CLAHE → 適応的二値化（推奨）

補足
- デフォルトは none のため、明示的に --preprocess-mode clahe+adaptive を付けない限り前処理は走りません（既存動作を壊さないため）。
- 単体指定でも watch モード（--watch）でも、低 Confidence 判定後に前処理再試行されます（watcher パス ReceiptProcessor にも同等実装済み）。
- --target-short-side でリサイズ倍率も手動調整できます。
